#Raspberry-Pi-Pico-W-Design-with-the-Brothers
This is some code for a Raspberry Pi Pico W with:
- an I2C LCD 2x16 Display
- Temperature and Humidity Sensor
- At least 1 RGB LED
- 3 buttons

> This code is licensed under an AS-IS basis. Nothing here is guranteed to work.Remember to double check your circuit and GPIO port numbers before plugging in.
